# Phone Agent – Claude שולט בטלפון אנדרואיד

אפליקציית אנדרואיד שמחברת את Claude (ברירת מחדל: `claude-sonnet-5-5`) לטלפון דרך **שירות נגישות**.
הסוכן רואה את המסך (צילום מסך + רשימת רכיבים), ומבצע הקשות, החלקות, גלילה, הקלדה, מקשי מערכת ופתיחת אפליקציות, בלולאה עד שהמשימה מסתיימת.

## התקנה
1. מורידים את `PhoneAgent.apk` מעמוד ה-Releases של הריפו (נבנה אוטומטית ב-GitHub Actions).
2. פותחים את הקובץ בטלפון ומאשרים "התקנה ממקורות לא ידועים".
3. באפליקציה: **פתח הגדרות נגישות** ← Phone Agent ← הפעלה.
   באנדרואיד 13 ומעלה המתג יכול להופיע אפור ("הגדרה מוגבלת"). במקרה כזה: **פרטי האפליקציה** ← ⋮ ← **התר הגדרות מוגבלות**, ואז מפעילים שוב.
4. מדביקים את מפתח ה-API ולוחצים **שמור מפתח**. המפתח נשמר מוצפן ב-Android Keystore ונשלח רק ל-`api.anthropic.com`.
5. כותבים משימה (או מקליטים 🎤) ולוחצים **הפעל**.

## בטיחות
- כפתור **עצור** צף על המסך כל עוד הסוכן רץ.
- לפני תשלום, מחיקה, שינוי הגדרות אבטחה או שליחת הודעה (כשהתוכן או הנמען לא הוגדרו במפורש), הסוכן מציג שאלה עם כפתורי **אשר / דחה**.
- אפליקציות שחוסמות צילומי מסך (בנקים, למשל) יופיעו לסוכן רק כרשימת רכיבים.

## מבנה
| קובץ | תפקיד |
|---|---|
| `PhoneAgentService.kt` | שירות הנגישות: צילום מסך, עץ רכיבים, מחוות, הקלדה, החלונית הצפה |
| `AgentRunner.kt` | לולאת הסוכן, הגדרות הכלים והנחיות המערכת |
| `ClaudeClient.kt` | קריאות ל-Messages API (thinking אדפטיבי, prompt caching, context editing לצילומי מסך ישנים) |
| `SecureStore.kt` | שמירת המפתח מוצפן |
| `MainActivity.kt` | מסך ההגדרות והמשימה |

## בנייה מקומית
```
cd android-agent
gradle assembleRelease   # Gradle 8.11+, JDK 17, Android SDK 35
```
המפתח `app/phone-agent.keystore` הוא מפתח חתימה לא-סודי להתקנה ידנית בלבד. הוא קיים כדי שגרסאות חדשות יותקנו כעדכון.
